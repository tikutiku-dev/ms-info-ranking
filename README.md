# モンスターサバイバル ランキングサイト

## 1. 概要

モンスターサバイバルのプレイヤー情報やシーズンごとのランキングを掲載するWebサイトです。

HTML・CSS・JavaScriptで構成されており、プレイヤー情報やランキングデータはJSONファイルで管理しています。

ランキングを更新するときは、基本的にJSONファイルを編集するだけで対応できます。

## 2. ファイル構成と各ファイルの役割

### ルートフォルダ

| ファイル         | 役割                                                     |
| ------------ | ------------------------------------------------------ |
| `index.html` | サイトの画面構成を定義するファイル。見出しやランキングの表示場所などを管理する                |
| `style.css`  | サイトのデザインを管理するファイル。色、文字サイズ、余白、ランキングのレイアウト、スマホ表示などを設定する  |
| `script.js`  | サイトの動作を管理するファイル。JSONデータの読み込み、ランキングの表示、シーズンの切り替えなどを処理する |
| `README.md`  | サイトの概要、各ファイルの役割、更新方法などを記録する説明書                         |

### `data/` フォルダ

ランキングやプレイヤー情報を管理するフォルダです。

| ファイル              | 役割                                       |
| ----------------- | ---------------------------------------- |
| `config.json`     | 現在のシーズンなど、サイト全体の設定を管理する                  |
| `players.json`    | プレイヤーのID、名前、アイコンなど、プレイヤー情報を管理する          |
| `season2.json` など | シーズンごとのランキングデータを管理する。シーズンごとにファイルを分けて保存する |

※シーズン番号や実際のファイル名は、現在のファイル構成に合わせて確認すること。

### `images/` フォルダ

サイト内で使用する画像を保存するフォルダです。

例：

* `season2.jpg`：シーズン2の画像

新しいシーズンの画像を追加する場合は、既存の命名ルールに合わせる。

## 3. 各ファイルを編集するタイミング

### プレイヤーの名前やアイコンを変更する

`data/players.json` を編集する。

プレイヤー情報を一元管理することで、複数のシーズンに同じプレイヤーが登場していても、情報を管理しやすくする。

### ランキングを更新する

対象シーズンのJSONファイル（例：`data/season2.json`）を編集する。

キル数などの記録を変更したり、必要に応じてプレイヤーの記録を追加・削除したりする。

### 現在のシーズンを変更する

`data/config.json` を編集する。

新シーズンに移行する場合は、必要に応じて以下も行う。

1. 新しいシーズンのJSONファイルを作成する
2. 新しいシーズンの画像を `images/` に追加する
3. `config.json` の設定を更新する
4. 公開サイトで正常に表示されることを確認する

新しいシーズンのファイルは、既存シーズンのファイルをコピーして作成すると編集しやすい。

## 4. 通常の更新手順

1. パソコンでVS Codeを開く
2. `ms-info-ranking` フォルダを開く
3. 更新したいJSONファイルを編集する
4. `Ctrl + S` で保存する
5. GitHubに変更をアップロード・反映する
6. 公開サイトを開いて、変更が反映されているか確認する
7. 必要に応じてスマートフォンでも表示を確認する

GitHubに変更を反映しただけでは、内容が正しいとは限らないため、公開サイトでの確認まで行う。

## 5. JSON編集時の注意点

* JSONの構文を壊さないようにする
* 文字列はダブルクォーテーション（`"`）で囲む
* 項目の区切りに必要なカンマ（`,`）を消さない
* 最後の項目の後ろに不要なカンマを付けない
* 既存のデータ形式をなるべく維持する
* 編集前のファイルをコピーしておくと、問題が起きたときに元に戻しやすい

### プレイヤーIDについて

プレイヤーIDがシーズンごとのランキングデータとの紐付けに使用されている場合、名前を変更してもIDは変更しない。

IDを変更すると、過去シーズンの記録と正しく紐付かなくなる可能性がある。

## 6. 新シーズン追加時のチェックリスト

* [ ] 新しいシーズンのJSONファイルを作成した
* [ ] 必要なランキングデータを登録した
* [ ] 新しいシーズンの画像を追加した
* [ ] `config.json` のシーズン設定を変更した
* [ ] 公開サイトでランキングが正しく表示されることを確認した
* [ ] スマートフォンでも表示を確認した

## 7. トラブルが発生した場合

### ランキングが表示されない

* JSONのカンマやダブルクォーテーションが正しいか確認する
* ファイル名や保存場所が正しいか確認する
* プレイヤーIDなど、参照先のデータが存在するか確認する

### 変更が公開サイトに反映されない

* 編集したファイルを保存したか確認する
* GitHubに最新のファイルが反映されているか確認する
* ブラウザを再読み込みする
* 必要に応じて強制再読み込みする

### 画像が表示されない

* 画像ファイルが `images/` フォルダに存在するか確認する
* HTMLやJavaScriptで指定されているファイル名と一致しているか確認する
* ファイル名の大文字・小文字や拡張子が一致しているか確認する

## 8. 運用方針

* プレイヤー情報は `players.json` で管理する
* シーズンごとのランキングは、それぞれのシーズンJSONファイルで管理する
* 現在のシーズン設定は `config.json` で管理する
* デザインの変更は `style.css` で行う
* 表示や切り替えの動作を変更する場合は `script.js` を編集する
* 画面の構成を変更する場合は `index.html` を編集する

普段のランキング更新では、なるべくHTML・CSS・JavaScriptを変更せず、JSONファイルの編集だけで対応する。
